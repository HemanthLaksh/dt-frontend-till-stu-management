# DocTutorials Admin Portal

The DocTutorials Admin Portal is a web-based administration application built with Next.js, React, TypeScript, and Tailwind CSS.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Redux Toolkit
- React Hook Form
- Zod
- Axios
- Recharts
- ESLint
- Prettier
- Husky and lint-staged

## Prerequisites

- Node.js
- npm
- Access to the required backend APIs

## Installation

Clone the repository and navigate to the project directory.

Install dependencies:

```bash
npm install
```
